# 第124轮：通道抠图＋AI透明度与真实结果检查

## 问题头

1. **承诺过通道，实际没有入口**：颜色通道曲线不能替代灰度Alpha抠图。新增独立通道预览与参数，接到范围事务。
2. **把透明像素数量当质量**：灰像素多不代表边缘正确。新增白底／黑底检查与真正透明PNG、灰度蒙版导出，实际查看原像素细节。
3. **简单混合伤浅色发丝**：低对比度通道不能辨别亮发丝与背景。根据前景／背景对比和离散程度决定通道权重，弱区主要由ViTMatte判断，并明确提示。
4. **可靠实体内部被洗灰**：默认保持深处不透明内部；薄纱／玻璃／枝叶孔洞另有透明内部选项，普通边缘不默认处理全部内部。
5. **原图分块矩形接缝**：ViTMatte的512px核心直接拼接会出现不一致。改384px步进、128px重叠和余弦权重，原像素输入不缩放；确定前景／背景保持。
6. **预览迟到覆盖最新设置**：控件一变立即使旧预览失效，再160ms合并计算；旧回复不能覆盖新黑白场。弹窗visible绑定回环已改为明确open／close事件。
7. **只修范围仍被要求输出新层**：AI对话可直接修改匹配的已有层范围，颜色／强度／层数保留、一步撤销；新目标先准备可继续编辑的独立范围。

## 产品入口

- 范围已准备 → **修细节 → 高级 → 通道抠图**。红／绿／蓝／亮度，自动推荐、反转、可键入黑白场、灰度、范围px；AI默认开启。内部透明／孔洞可另选。
- **查看 → 白底抠图／黑底抠图**，既有叠色、黑白Alpha和调色效果保持。
- **导出 → 透明选区 PNG／黑白蒙版 PNG**。当前草稿可直接导出，默认透明选区；不强制先建层。当前层范围修改以临时层快照合成，导出不更改草稿、图层或历史。
- 对话可说“只选择左上角树枝，结合通道和AI保留细枝与针叶，排除天空和山”，也可说“用通道和AI细化当前头发图层的边缘，保持原来的调整颜色和强度”。

## 架构与组合

AI理解对象与意图 → 已有准确范围复用或本地像素分割 → 通道比较与灰度引导 → 原图ViTMatte透明度 → 强对比灰度辅助／弱对比AI判断 → 多背景检查与局部补选／擦除／透明细化。

`matting/channels.py` 不把任意RGB值直接当全图alpha。仅目标附近可扩，较远alpha保持；语义皮肤零支持不能越过。前景／附近背景采用鲁棒统计，黑白场以分位数减少有光照梯度的天空残留。内部模式且强区分时，确定黑场可清除粗范围内的背景孔洞；弱区不用强灰度覆盖AI。用户调控和自动推荐都通过严格协议。

最多32M ROI；AI继续受4M未知／128块／180秒约束，需要可靠前景／背景，否则保留范围而非假结果。原图灰度bitmap保分辨率。重叠合并只为未知像素分配累加与权重，避免创建多个24MP float画布；规划预算同步使用新步进。

`channel_mask.py` 管预览／防过期／应用，`channel_auto.py` 管对话完整事务：channel_mask action仅当前草稿、匹配局部层或单一object定位，不夹带调色。云端仅规划，本地计算通道和透明度；新目标不发布中间粗范围。取消、来源SHA、代次、全层快照、原草稿与绑定核对，最终一次提交。所有阶段可见，可取消。

## 亲自实测与判断

原run.py／完整Main.qml／Qt offscreen/software／QTest／1440×930，使用真实已配置qwen3.8-flash和用户授权的ppp大图。没有控制用户旧窗口，也未验证原生输入法或桌面鼠标体验。

| 场景 | 实际结果 |
| --- | --- |
| lake.jpg 2000×1333，AI文字选择左上枝条 | 最终22.260s、1次真实聊天HTTP；通道＋本地AI约1.3s；原尺寸透明PNG、Alpha逐字节一致，QML0 |
| ppp `*1607_23.jpg` 4016×6016，已有头发层 | 最终14.634s、1次真实聊天HTTP；原图透明度2.6s；同层／参数／层数保持，文档一步撤销与重做、透明PNG验证，QML0 |
| 手动通道两种照片 | 实际打开弹窗、推荐、取消／重试、草稿撤销／重做、同层保存、项目保存／重开；源与设置SHA保持 |
| 合成透明织物、有孔洞、已知灰度真值 | 纯通道和可控AI混合的误差<1/255；明确是合成数值测试，不代替真实薄纱测试 |

本人查看了原像素Alpha与白底合成。初始直混方案切掉浅色发丝，已经撤回；弱区AI方案更柔和，但发丝仍有宽灰边与原背景颜色，不能宣称每根正确。枝条首次推荐残留粗形状淡灰晕，改鲁棒黑白场后明显清理，同时保留细枝。完整前景山／树测试还暴露分块矩形接缝，已修重叠合并。旧失败和中间输出保留在ignored证据。

测试脚本曾在重做后预览未就绪时点禁用按钮、读取Qt图像enum、控件布局变化尚未稳定、错误使用不存在的invertSelection槽；这些驱动失败保留并修正，没有绕过产品检查。首UI断言要求默认通道在无渐变夹具里必须改变范围不合理；改为真正键入不同白场检查灰度变化，顺便补上SpinBox可键入操作。

最终相关回归结果补于UX audit；重复集合不相加，不称全仓库测试。验证内容包括边缘重叠无跳变与原确定区、原图数据／原像素尺寸、迟到预览、对话范围／能力限制、取消／过期／失败保持、透明／灰度原尺寸导出及原alpha相乘、未提交层范围的临时合成、便携生成层／检查策略与完整QML窗口。

## 未完成

真实薄纱仍待专项验证；头发背景相近、玻璃反射和主体颜色多变仍可能不准。尚未实现前景颜色去污染，透明边缘RGB可能残留旧背景，黑白背景能暴露问题；调整alpha不能解决全部颜色污染。新生成式修脸仍会出现五官位置变化，候选检查已拦截，稳定一键大片未达成。继续以可见效果与人工判断衡量，不能以工具数量或HTTP成功冒充效果好。

# iPhoto 1.4.1：画布操作升级与验收

2026-09-23。本轮针对缩放、拖动和画布易用性；保持 1.4 项目格式。

## 问题与实施顺序

旧画布只有适应与固定 1.6 倍两种尺寸，只有浏览工具且放大时才能平移。缩放缺少百分比、鼠标锚点和临时抓手；画布空间随面板变化时也没有明确的视图保持规则。

已依次完成：独立视图几何 → 键盘/鼠标路由 → 导航与缩放控件 → 有界覆盖绘制 → 真实 Qt 事件回归 → 高 DPI / Windows 验收。

## 已实现的操作

| 操作 | 方法 |
|---|---|
| 临时拖动 | 空格＋左键拖动，或中键拖动；松开保留原选区工具 |
| 抓手 | H；双击抓手按钮或抓手状态下双击画布，适应窗口 |
| 缩放工具 | Z；单击放大，Alt＋单击缩小，左右拖动连续缩放 |
| 鼠标锚点缩放 | Alt＋滚轮；也支持 Ctrl＋滚轮 |
| 普通移动 | 滚轮上下、Shift＋滚轮左右；支持触控板 pixelDelta 二维滚动 |
| 档位缩放 | Ctrl++ / Ctrl+=、Ctrl+− |
| 复位 | Ctrl+0 适应；Ctrl+1 恢复原图 100% 尺寸比例 |
| 百分比 | 底栏输入并回车；Esc 放弃；无效输入恢复当前值 |
| 快速定位 | 右下导航图显示可见范围，点击或拖动定位；可隐藏 |
| 滚轮偏好 | “视图”或画布“?”菜单切换直接滚轮缩放，本次会话有效 |

另支持 Ctrl＋空格临时缩放；若 Windows 输入法占用该组合，使用 Z 或 Alt＋滚轮。主要操作参考 [Adobe 官方 Photoshop 快捷键](https://helpx.adobe.com/content/dam/help/en/photoshop/using/default-keyboard-shortcuts/photoshop-keyboard-shortcuts.pdf)。中键拖动和导航图是本应用的交互扩展。

适应模式随窗口和 AI 面板展开/折叠自动调整；其他比例保持图像中心位置。小图也可拖动，边界保留可见部分，避免完全拖丢。透明照片显示棋盘背景。

输入文字、打开模态设置/文件对话框或菜单时，导航快捷键让出焦点。窗口失焦清除临时按键，避免抓手卡住。选区中途改变缩放/窗口尺寸/按空格，会取消未提交笔画，避免坐标串位。AI 或本地处理忙碌时仍能浏览、缩放和平移。

## 实现与性能

`viewport.py` 独立管理尺寸、DPI、锚点、边界和临时按键；`CanvasViewport.qml` 处理图像、蒙版、选区与导航手势；`CanvasOverlays.qml` 只绘制屏幕范围的轮廓；`CanvasNavigator.qml` 复用现有预览。界面组合和百分比输入保留在 `CanvasPane.qml`。扩展约定见 [仓库说明](../../docs/repository-guide.md)。

导航只改变显示变换，不增加文档历史、脏标记、AI 请求或合成任务。图片与蒙版共享同一坐标系。覆盖 Canvas 的大小始终与可见窗口相同，3200% 时也不按放大后的图片分配纹理。

独立运行 `scripts/benchmark_canvas.py`：Qt Quick 软件后端、1440×930、DPR 1、内置 2000×1333 湖景，每档预热 10 帧后测 70 帧。测量包括同步截图读回，**不是显示 FPS**。

| 缩放 | 帧与读回中位时间 | P95 | 额外合成请求 |
|---|---:|---:|---:|
| 50% | 14.753 ms | 17.286 ms | 0 |
| 100% | 14.518 ms | 18.142 ms | 0 |
| 800% | 14.131 ms | 17.879 ms | 0 |
| 3200% | 14.259 ms | 17.429 ms | 0 |

四档覆盖层都为 1032×608 DIP，QML 警告为零。原始数据：[canvas-v141-benchmark.json](../../artifacts/canvas-v141-benchmark.json)。该测试不测全尺寸导出、GPU 性能或云端耗时。

## 验收结果

- 完整回归：**158 passed, 1 skipped，104.20s**。唯一跳过项为沙箱下无法访问 Windows 凭据库；正常用户会话补跑该现有测试 **1 passed**，使用临时随机凭据。合计 **159 项不同测试通过**。
- 新增 15 项几何测试：鼠标锚点、缩放极值、平移边界、窗口重排、DPR 1/1.25/1.5/2、极窄长图。
- 新增 6 项完整窗口测试：两种尺寸各三个流程，真实 QTest 键盘/鼠标/滚轮，涵盖百分比、导航、比较线、临时手形、选区坐标、未完成笔画取消、文字焦点、模态窗口、失焦恢复、轮廓缓冲上限。
- `QT_SCALE_FACTOR=1.5` 重跑六项 UI 测试：**6 passed，20.97s**。
- 正常 Windows 平台重跑 1080×700 的三个 UI 流程：**3 passed，10.57s**。最初被 pytest 默认临时目录的 Windows 权限阻止；换成项目内全新的独立临时目录后通过，未改变应用权限。
- `ruff check src --select F` 与 `ruff format --check src` 均通过；QML 加载与运行无警告。
- 已检查大窗口和小窗口截图：底栏、抓手/缩放按钮与导航图均可用；原生窗口截图另存 `artifacts/iphoto-v1.4.1-native.png`。

重复运行用于不同环境验证，不重复计入 159 项。全程未调用真实云端模型，本次画布操作不需要 Key。

## 当前边界

100% 按原图尺寸和物理屏幕像素计算；最长边超过 1600 的图像仍使用 1600px 合成代理，底栏与缩放提示会明确标注。**这不是原分辨率细节预览**，高倍缩放不创造额外细节。后续高清瓦片需要独立处理坐标、局部滤镜边缘和异步结果，不能简单放大代理图替代。

本轮不包括画布旋转、透视/裁切、标尺参考线、多文档标签、触控捏合，也未改变导出的原图分辨率。

# iPhoto v1.2 升级方案与执行计划

日期：2026-09-22。面向个人使用、Windows 优先，继续 Qt 6 / PySide6 / QML，不引入 Electron 或 WebView。

## 1. 本次目标

从「整张照片调六个参数」升级为「图层 + 独立选区 + 可追溯 AI 工作流」。用户明确要求先定计划再实现，本文件先于实现建立；完成情况另记在交付记录中。

典型流程：打开照片 → 新建“天空”图层 → 输入“选中天空”生成 AI 选区草稿 → 检查覆盖范围并确认/补选 → 请求压低天空高光 → 只修改天空 → 再建人物图层 → 保存项目 → 下次继续编辑和查看对话。

## 3. 数据与渲染方案

- `Layer = id, name, visible, opacity, recipe, locked, mask`。底部到顶部顺序合成，参数作用于下层合成结果。原图不作为可删除调整层；初始“全图调整”蒙版为全图。
- 一个蒙版可以包含多个形状/笔画，但它们合并为该层唯一的选区。矢量坐标归一化到 0…1，与窗口缩放无关；绘制/导出都按实际图像尺寸栅格化。AI 使用显式 0…999 坐标协议，再验证转成归一化多边形。
- 新层为空选区，禁止默认把局部要求施加到全图。蒙版支持有限数量操作和点数，防止异常模型返回或项目文件耗尽内存。
- 内羽化通过模糊后与原始硬选区相乘保证选区外为零。遮罩叠加仅用于预览，不进入照片导出。
- 点运算沿用 LUT；锐化/柔化使用 Pillow，半径按照片尺寸比例换算；预览和原尺寸共享配方与蒙版语义，不承诺缩略图与全尺寸空间滤镜逐像素一致。
- 继续独立 QProcess 执行渲染与导出；只保存一份当前合成结果，逐层处理，不缓存每层全尺寸 float 图。

## 4. AI 方案与真实边界

沿用已有千问 Token Plan、千问按量、百炼、OpenAI 和兼容接口配置。没有额外的 Key 输入入口。图片仍为去 EXIF 的缩略图，不上传原始文件路径。

三种任务分别验证结构：修图/建议返回参数与文字；选区返回目标轮廓多边形。普通建议不自动修改照片。局部参数请求同时携带当前层名称和选区描述/轮廓，让模型知道作用范围。最近对话限量传递；照片里的文字和历史记录均为非可信内容，不作为系统指令。

本版 AI 选区是 VLM 生成语义粗轮廓，不是经过精度评测的像素分割模型。须显式确认草稿；允许漏选/错选后的手动补选。无法识别时返回 unsupported，不偷偷退化为全图。复杂头发、玻璃、孔洞和遮挡是已知限制。SAM 等本地分割模型作为后续可插拔实现，不能仅安装一个包就宣称完成。

参考官方资料（2026-09-22）：[千问视觉理解](https://help.aliyun.com/zh/model-studio/vision-model)、[视觉坐标说明](https://docs.modelstudio.console.alibabacloud.com/zh/model-studio/vision)。模型提供视觉理解/定位能力；多边形草稿工作流为本项目设计，官方能力不等于保证精细分割效果。

## 5. 存储、错误与兼容

项目使用可读 JSON（`.iphoto` / `.json`），版本 1.2，原子替换当前项目；另存为不覆盖未知文件。源图不内嵌，移动照片后需要还原原路径。项目不保存 Key 或 Authorization。对话保存在本地、随项目携带；发送上下文只取最近若干条，界面明确告知。

保存恢复副本失败必须提示。每个编辑会话有独立恢复文件，避免多窗口互相覆盖。提供最近恢复入口，不自动覆盖用户当前作品。错误、取消、unsupported 进入对话；任务绑定照片代次和图层，过期结果不应用。测试用合成图片和假 Key，不读取用户 Key 做自动计费测试。

## 6. 实施步骤

1. 建立本计划；实现独立图层/蒙版/项目校验模块及 12 项引擎。
2. Worker 接入逐层渲染、蒙版叠加与原尺寸导出。
3. Editor 接入图层状态、统一历史、工程迁移/自动恢复、对话持久化。
4. AI 接入建议/选区协议、上下文、草稿确认和错误记录。
5. QML 调整工作区，完成选择工具和可读对话，保留既有 AI 设置。
6. 验证蒙版外不变（预览/PNG 导出）、叠层/隐藏/顺序、撤销、保存恢复、无效 AI 拒绝、聊天建议不自动修改、UI 最小尺寸与截图；更新交付记录并启动可体验版本。

## 7. 后续版本，不在本次冒充完成

- 像素级语义分割（SAM / 专门天空与人像模型）、细发抠图与质量评测集。
- 污点修复/生成式擦除、智能降噪、RAW/16-bit 宽色域、局部曲线/HSL、透视/裁剪旋转（需统一变换蒙版坐标）、批处理。
- 图层组/混合模式、安装包签名/自动升级、跨平台正式测试、账户同步。

发布前应补一组用户真实照片的 AI 效果验收；通过模拟接口测试只能证明协议与交互，不代表真实模型选区质量。

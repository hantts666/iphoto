# iPhoto V1 方案与执行计划

状态：已交付本地编辑原型，并完成 0.2 版 AI 设置与云端参数规划接口。用户指定增加千问 AI 平台 Token Plan 个人版适配，已单独加入服务商预设。已确认自用、Windows 优先、Qt/PySide6/QML、通用单图修图与先输入要求的流程。真实账号联调和照片质量盲评待用户配置 Key 后进行；详见 [AI 连接指南](../../docs/ai-connection.md)。

本目录用于把产品需求转换为技术决策、开发任务和验收证据。根据用户最新指令，已先实现可试用的 Qt 界面和真实本地调色，采用 JPEG/8-bit PNG 与本地规则作为原型默认值；尚未调用收费图像分析 API。启动方式见 [项目 README](../../README.md)，实测范围见 [原型验证记录](../../docs/prototype-validation.md)。

第 1 轮已完成。第 2 轮确认使用流程、照片来源、云端方式和硬件约束；已确认采用先输入具体要求、AI 再修图的流程。第 3 轮只解决仍会影响开工的验收条件。用户可以一次自由补充多项，不要求按表格逐项回答。

# iPhoto 1.4：对象选区与可扩展工作区

## 本轮目标

1. 用本机保存的千问配置，在内置示例上复现文字选区问题；记录真实结果、延迟和失败原因，凭据不进入文件或日志。
2. 增加画面元素清单：先识别可见对象，按类别勾选、组合或在画布点选，生成独立选区草稿。保留文字选区与手动修整，明确区分对象点选和颜色魔棒。
3. 文字选区采用更清晰、紧凑的图片与坐标协议；边缘优化改为明确操作，避免默默改变用户目标。失败保留原草稿。
4. 真正支持多层图层组：组内排序、移入/移出、展开折叠、继承可见性、组不透明度、撤销与项目持久化。明确调整层的合成语义。
5. 按功能拆分 Python 服务与 QML 区域，保留单一 Qt Editor 门面，避免 Qt 属性继承冲突；编写仓库说明和扩展约定。
6. 增加协议、层级、选区组合、实际鼠标键盘、项目恢复和性能测试。性能在独立进程中测量；真实 API 与模拟测试分开标注。

## 执行顺序与验收

- 基线：读取现有代码，真实千问选区调用，保留结果图和结构化测试摘要。
- 数据与协议：对象清单校验、掩码集合运算、层级校验/合成、旧项目兼容。
- 工作区：元素浏览器、对象点选、组操作、功能模块拆分，持续运行针对性测试。
- 验收：完整自动测试、真实 API 回归、两个窗口尺寸 UI 检查、独立性能测量、启动新版。

“识别画面元素”是可复用的候选清单，不能保证穷尽所有微小物体或获得发丝级边缘。轮廓和边缘质量需要以实际图像检查，不以 HTTP 成功替代效果验收。

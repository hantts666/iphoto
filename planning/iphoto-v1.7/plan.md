# iPhoto 1.7 执行计划

2026-09-24。目标：原图分辨率贯穿编辑与导出；选区流程更清晰；面板可折叠；改善调色后的混合边缘；提供可直接启动的 Windows 便携包。

1. 核验原图 / 画布 / 蒙版 / 导出尺寸，移除隐藏的分辨率降级，给导出增加尺寸与格式说明。AI 模型内部仍按模型输入尺寸做初选，边缘随后在原图上细化。
2. 将选区流程拆成选目标、修边缘、应用三个阶段。提供可折叠的基础调整、色彩、细节、选区修正和图层属性；保留组展开、画布快捷键和草稿撤销。
3. 将透明度求解改成按原图分块读取，限制每块内存。新增可关闭的边缘色彩保护，单独验证其局部调色行为，不把 alpha 置信度当成透明度。
4. 修复发现的交互状态问题，覆盖预览、确认、取消、撤销、保存恢复、原图导出；原生 Qt 检查大小窗口。
5. 采用 PyInstaller 文件夹便携包，独立图像 worker，随包提供必需运行时与已验证的本地模型。只打包明确列出的代码和资源，不包含 Key、个人配置、测试照片或工作记录。
6. 在包内验证启动、真实处理、保存、导出和退出，最后生成 ZIP、校验值及使用说明。

验收重点：原图像素尺寸不被静默缩小；PNG 导出与合成像素一致；新蒙版按源尺寸保存；旧项目可读；最终零蒙版像素完全不变；零调整不改变照片；面板折叠不丢状态；包无需外部 Python。

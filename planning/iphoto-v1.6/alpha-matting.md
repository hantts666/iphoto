# iPhoto 1.6：透明边缘、局部调色与白边

2026-09-23。用户反馈：不规则山林边缘在局部调色后出现或加重白边。本轮完成行业调研、现有链路检查、CPU 透明度细化与可撤销预览。**没有把“所有白边已解决”作为验收结论。**

## 1. 问题的正确拆分

选区分割回答“哪些像素属于目标”，边缘抠图（alpha matting）回答“一个混合像素有多少属于目标”。一个像素可能是 30% 树梢、70% 远山；这不等于整层不透明度，也不等于模型有 30% 信心，更不能靠把轮廓无限加密解决。

在线性光下，成像近似为 `I = αF + (1−α)B`。透明度只是未知量的一部分。单张照片本来就无法唯一恢复所有前景、背景和透明度，需要空间、颜色或学习先验。

用户已确认是在局部调色后更明显。因此需要同时区分：

1. 错选、漏选或者边缘过度内缩，导致一条混合像素几乎没有参与调整。
2. 对半透明蒙版重复衰减，导致边缘的调整强度不连续。
3. 即使 α 合理，直接调节已经混合的 RGB，也不等价于只调整其中的前景颜色。
4. 原图的亮岩石、逆光、锐化光晕本身也可能被对比放大。用户提供的是放大局部，不能仅凭这张截屏认定每个亮点都是错误边缘。

## 2. 行业实践与选型

| 参考 | 直接支持的做法 | iPhoto 的取舍 |
|---|---|---|
| [Adobe Refine Edge](https://www.adobe.com/learn/photoshop/web/make-precise-selections-refine-edge) | 初选后另设边缘半径、细化画笔、覆盖/黑白检查；颜色净化输出到带蒙版的新图层 | 将“选哪里”和“边缘如何混合”分开；颜色修正应作为独立操作，不能藏在羽化里面 |
| [Matte Anything 官方实现](https://github.com/hustvl/Matte-Anything) | SAM 初选 → 自动 trimap → ViTMatte；另有透明材质提示 | 借鉴模块边界。完整研究栈包含多套模型和依赖，本机暂不整套照搬 |
| [PyMatting 文档](https://pymatting.github.io/) | trimap 明确前景、背景、未知；分别提供 alpha 估计和前景估计；指出仅给原图乘 alpha 仍可能有光晕 | 本轮采用其 closed-form 求解器作为可验证的 CPU 基线，后续单独评估颜色分离 |
| [ViTMatte 官方仓库](https://github.com/hustvl/ViTMatte) | 图像与 trimap 驱动的学习型抠图 | 下一阶段的质量候选。尚未在本机安装、测速或验证，不能宣称当前已经达到它的质量 |
| [PyMatting 前景估计接口](https://pymatting.github.io/foreground.html) | 单独估计 F，部分接口也估计 B | 用于后续局部调色补偿与换背景实验，不应直接替换整张原图 |

选择 PyMatting 是结合本机 Windows / CPU 的工程决策，**不是认定它是当下质量最好的模型**。纹理复杂、相近颜色、错误 trimap、玻璃和大范围雾气都可能超出这条经典算法的能力。PyMatting 使用 [MIT 许可证](https://github.com/pymatting/pymatting/blob/master/LICENSE.md)；依赖固定版本，不运行项目文件或 AI 返回的代码。

## 3. 本轮已实现

### 连续透明度细化

独立目录 `src/iphoto/matting/`：

- `trimap.py`：从已有选区构造前景 / 背景 / 未知边缘；1–24px 范围，保留小孔洞的确定背景种子。已有半透明区域仍视为待估计区域。
- `solver.py`：延迟加载 PyMatting，sRGB 解码为线性光，调用 closed-form alpha matting。256px 核心区配 64px 周边上下文；只提交核心区结果，避免给分块边界加虚构的硬约束。
- `service.py`：校验输入、取消旧羽化作为推断依据、统一生成连续灰度蒙版及耗时信息。
- `controllers/matting.py`：后台请求、草稿替换、取消、对话记录；不承载求解逻辑。

细化会在待判断带内重新估计范围，可能补进原先漏掉的边缘；因此结果仍是草稿，需要确认后才替换图层。明确的远处前景 / 背景不重算。失败、取消或过期结果保留原选区，不偷偷退回多边形或高斯模糊。

### 修复蒙版链路

原有内羽化使用 `alpha × blur(alpha)`，会把均匀的 50% 透明度近似压成 25%。现在改为取当前覆盖度和模糊覆盖度的较小值。二值蒙版的原有内羽化行为不变；半透明蒙版不会被平方衰减，零覆盖度仍保持零。旧项目中“半透明位图 + 羽化”的边缘效果会随该修复变化。

新的透明度资产带有 `sampling: "alpha"`，缩放时使用无过冲的线性插值，并保护最近邻映射后的零覆盖区。旧资产继续按原方式读取。内部使用浮点求解，项目仍保存 8-bit 灰度 PNG；不宣称是 16-bit 精度流程。

项目协议升级为 1.5；新版本继续读取 0.1、1.2、1.3、1.4。新项目不可用旧版 iPhoto 覆盖保存。

### 可见、可撤销的交互

右侧“选区”新增“透明边缘”：范围调节、“细化透明边缘”、取消。AI 分区草稿也可逐区细化。保留草稿撤销 / 重做、项目保存、输出图层及替换蒙版流程。

预览新增“调色效果”：将草稿临时交给当前图层参数渲染，实际图层和历史不变。这样可以针对“压暗后出现白边”检查结果，而不仅看绿色覆盖。当前层没有调整参数时，此预览自然没有调色差异。

建议使用：选中已有局部调整层 → 载入层蒙版 → 先用 8px 细化 → 切换黑白透明度 / 调色效果 → 放大检查 → 替换当前层蒙版。不合适先撤销，再调整范围或补选 / 减选。

## 4. 验收与性能

执行命令与生成的素材不使用云端服务，不读取真实 Key。测试照片为内置湖景和受控合成图，用户提供的截图没有上传到第三方。

```powershell
.venv\Scripts\python.exe -m pytest tests/test_matting.py -q
.venv\Scripts\python.exe scripts/qa_alpha_matting.py --natural
.venv\Scripts\python.exe scripts/qa_matting_ui.py
```

- 全量回归：188 passed、1 skipped，192.55s；跳过的是沙箱无法访问 Windows 登录凭据会话的原有测试。Ruff 检查和格式检查通过，pip check 未发现依赖冲突。
- 新增 8 项回归覆盖：透明度被平方的缺陷、插值与零覆盖保护、trimap 与孔洞、真实求解与跨块接缝、取消 / 过期 / 失败、真实 worker 的预览 / 撤销 / 保存 / 导出。
- 已知 alpha 的 480×320 受控混合图，仅统计 `0 < α < 1` 的像素，平均绝对误差：二值 0.25076，旧边缘估算 0.11364，本次 0.00181。**只代表此受控样本，不是自然照片准确率。**
- 内置山林：1600×1066，57,834 个未知边缘像素，12 个求解块；同进程已初始化后细化约 3.93s。
- 原生 Qt 实测点按钮、切换预览、撤销重做并保存项目，首次在新 worker 内操作至显示约 7.61s；检查 1440×930 与 1080×700 两种逻辑尺寸，未收到 QML 警告。
- 全新依赖第一次导入触发 Numba 编译，本机约 233.51s。安装脚本已加入预初始化，此机器缓存已生成；更换 Python / 包版本可能重新编译。
- 资源限制：最多 450,000 个未知像素；每块 Cholesky 预条件器最多 4,000,000 项，最多 250 次 CG 迭代；块间检查 90s 预算。这个时间限制不是可抢占的硬截止。取消会丢弃结果，仍需等当前计算结束。

输出：`artifacts/alpha-matting/report.json`、`alpha-comparison.png`、`adjustment-comparison.png`、`forest-comparison.png`、两张原生界面截图、`ui-report.json`、`matte-demo.iphoto`。

## 5. 尚未实现的两类提升

### P1：更可靠地告诉算法“哪里不确定”

增加专用边缘细化画笔：笔画标记未知区域，不直接把它涂成全选或全不选；同时支持固定前景 / 背景笔画。透明物体内部可能也是未知区，不能永远只沿外轮廓生成 trimap。接入 ViTMatte 等可替换后端前，用同一套自然照片和 trimap 对比。

验收：树梢、发丝、细网、低反差边缘、雾气均有检查样例；有真值时比较 SAD / MSE / 梯度误差，无真值时保存同位置、同参数的人工对照。增加原图局部重算，解决目前最长边 1600px、导出只放大蒙版的细节上限。

### P2：针对局部调色的边缘颜色处理

目前合成还是 `αT(I) + (1−α)I`。目标前景真正独立调色更接近 `αT(F) + (1−α)B`。所以透明度细化本身不能保证所有白边消失。

下一步先评估 F / B 估计，使用保留原图的差量形式 `I' = I + α(T(F)−F)`。必须在线性光中定义和验证，并为估计不可靠的区域降低或关闭补偿；不能把不稳定的 F 整片覆盖回照片。颜色净化单列强度与预览，默认关闭，输出独立、可撤销的结果。它与单纯 alpha 修正的入口和记录应分开。

验收：零调整精确等于原图；最终蒙版为零处逐像素不变；不会把真实白花、雪、亮岩石或逆光误染成周围颜色；黑 / 白 / 灰背景检查以及局部增减曝光对照均通过。涉及透明导出时另测 straight / premultiplied alpha，防止二次乘 alpha。此部分本轮没有接入产品，也不把研究公式当成已验收的功能。

# iPhoto 1.7.0

基于 Qt 6 / PySide6 的 Windows 原生修图工作室。采用独立选区、调整图层和 AI 助手的操作方式，无需 Electron 或 WebView。

双击 [start-iphoto.cmd](start-iphoto.cmd) 启动。新窗口标题应为 **iPhoto 1.7.0**，已打开的旧窗口不会自动更新。开发环境为 Python 3.12；其他电脑先运行 `scripts/setup.ps1`，再运行 `scripts/setup_segmentation.py` 安装选区模型。目前是源码与启动器，尚无独立安装包。

## 本次重点：透明边缘与调色预览

已有局部调色出现白边时：右侧选中图层 → 载入层蒙版 → 在固定输出栏点“去修边” → “按原图细化透明边缘”（默认 8px）→ 预览切换“调色效果”检查 → “应用到当前层蒙版”。结果仍是可撤销的草稿，原图不变。也可以查看黑白透明度，确认边缘有连续灰度，而非只有全选 / 不选。原图级细化在独立进程运行，点“取消边缘细化”或按 Esc 会立即恢复编辑并保留原选区。

本地 PyMatting 根据前景、背景与未知边缘估计透明度；修复了内羽化把半透明覆盖度再次相乘的问题。该功能无需 Key。安装脚本会预初始化求解器，第一次编译可能需要数分钟；本机已完成。树枝、毛发等边缘仍需检查，颜色污染和复杂透明材质不能只靠 alpha 完全解决。

[行业调研、实现和后续验收计划](planning/iphoto-v1.6/alpha-matting.md)。当前项目协议为 1.7，仍可读取旧项目。

## 像素自动选区

AI 只定位目标；本地 EfficientSAM 从照片生成位图蒙版，不再将 AI 多边形直接当成最终选区。按 **S** 在目标内部点击，**Alt＋点击**排除背景，不需要云端 Key。顶部可“退一点”或开始“新目标”；已有草稿在右侧点“补点修正”。框选目标后可点“重新贴边”。检查复杂边缘后，点“开始调整此范围”。

文字选区、元素组合和 AI 分区均通过像素分割。首次需要编码图片，通常需数秒；进入像素工具或分析画面时会在后台准备，同图后续目标复用特征。等待中或正在执行的点选都可点击取消或按 Esc；正在执行时会结束独立像素进程，原选区保留，下一次点选需重新启动进程。后台元素轮廓不会阻塞画框或换照片。分割后可以另做透明边缘细化；最长边 1600px 的蒙版仍不等于原图级细节。

## 按你要做的事情开始

**整张照片调色**：打开 JPEG / 8-bit PNG、MPO 或相机 RAW；点击右下角“全图调整”图层，右侧即显示滑杆，也可用下方 AI 助手描述要求。再次点击该图层可返回范围与元素。手动调过的参数会锁定，AI 保留这些值；右键滑杆行可解锁或重置。

**先看清画面里有哪些对象**：未选中图层时，右侧“范围”模块同时显示选区工具与画面元素。点击“分析画面”；识别后悬停元素行可在画布预览。勾选多个对象后点 **调整已选对象**，识别完成即进入局部调整。需要先修边或组合已有范围时，点“组合…”。按 O 可在画布点选；重叠处优先较小对象，清单可明确选择大背景。Shift 添加、Alt 减去。

**只改一个区域**：在右侧“范围”模块描述“选中天空，排除树枝和山峰”。首次分析元素，随后逐对象生成像素蒙版；后续描述复用清单。清单没包含目标时，用“AI 直接识别”补充，或按 S 像素点选、M 框选、L 套索、B 画笔手动选。W 是颜色魔棒，只选连续相近颜色。检查边缘后点 **开始调整此范围**；新层会自动选中，右侧随即出现只影响该范围的滑杆。选区草稿也可用于内容感知填充。

**修人像**：先选中面部皮肤或人物范围，再点调整面板的 **轻磨皮**，或在“细节与人像”中精调磨皮强度。磨皮采用保边平滑，只作用于当前图层范围；它不会自动找出脸或祛痘。小瑕疵可用左侧“修复”画笔处理。AI 的单层调整和自动分区也能设置磨皮参数；需要只磨面部时，请让 AI 先建立相应局部区域。

**直接让 AI 自己分层**：下方助手默认是 **智能修图**。输入“人物面部轻磨皮，背景保持清晰”或“人物提亮、天空压暗”，AI 会判断是修改当前图层，还是为局部目标建立独立调整层。局部方案经过参数和坐标校验，再由本地像素模型生成蒙版并自动建层；整组可一步撤销，点图层蒙版缩略图可修边。若模型首次回复格式或参数不合要求，助手会提示并自动校正一次；旧式“请先手动选区”磨皮回复也会再尝试分区规划，这些情况可能多一次接口调用。如果想先检查每个区域，切换到 **分区预览**，逐区确认后点 **开始分区调整**。磨皮不会自动祛痘，修复画笔仍适合小瑕疵。

第一次用云端服务，在右上角 **AI 设置**填写自己的 Key。千问 Token Plan、百炼、OpenAI 和兼容接口配置见 [AI 连接指南](docs/ai-connection.md)。只给建议模式会保存文字和候选参数，点击“应用建议”后才修改图层。

## 画布缩放与拖动

按住 **空格拖动**，松开回到原工具；**中键拖动**也可临时平移。按 **H** 使用抓手，双击画布或抓手按钮适应窗口。按 **Z** 使用缩放工具：单击放大，Alt＋单击缩小，左右拖动连续缩放；双击缩放按钮恢复 100% 比例。

**Alt＋滚轮**围绕鼠标位置缩放；普通滚轮上下移动，Shift＋滚轮左右移动。偏好直接滚轮缩放时，在“视图”菜单或画布右下角“?”切换（本次会话有效）。Ctrl＋加减按常用档位缩放，Ctrl+0 适应画布，Ctrl+1 回到原图 100% 尺寸比例；也可在底部直接输入百分比并回车。通常支持 1%–3200%，超宽长图的适应比例可低于 1%。

离开适应模式后，右下角导航图显示可见范围，可以点击或拖动定位。缩小图像也能拖动，边界会保留一部分图像，Ctrl+0 随时找回。调整窗口、展开 AI 助手时，适应模式自动重排；其他比例保留视图中心。透明 PNG 使用棋盘背景。

缩放按原图尺寸与屏幕 DPI 计算。全图先显示最长边 **1600px** 的快速预览；放大后会在独立进程按可见区域加载原分辨率细节，包括当前图层调整。显示蒙版时，手绘形状和笔画的边缘也在该区域按原图像素显示。底栏显示当前区域的加载状态。视口闲置约 20 秒或缩回适应画布时会释放细节进程；闲置时保留已显示的清晰图块，再平移会按需载入。缩放和平移不会修改照片、创建选区或增加撤销历史；导出仍按原图像素合成。

## 选区与蒙版的区别

- 绘制和 AI 生成的是**独立选区草稿**，已有图层不变；“调色效果”模式可临时显示草稿结果。草稿有独立撤销/重做记录，Ctrl+D 取消草稿。
- “开始调整此范围”会把选区变成一个新的局部调整层；“更多…”中的“替换当前层的范围”可修改已有图层的蒙版。
- 点击图层蒙版缩略图，或“载入蒙版”，把原蒙版取出来继续修正。默认画笔为添加；X 切换添加/减去。
- 预览可选绿色覆盖、黑白透明度、调色效果或只看照片。羽化向内进行；位图可以保留孔洞、零碎区域和灰度过渡。
- 图层区的“＋ 调整层”建立全图调整层。每层一个蒙版；选中组时会在组内创建。
- “编组”或 Ctrl+G 将当前层放进新组，支持四级组嵌套，合计 32 个图层与组。可移入其他组、移出一级、展开折叠。组内先合成，再应用组蒙版与不透明度；隐藏组会隐藏所有后代。删除组会删除组内各层，可撤销。

## 本地图像能力

“图像能力”列出依赖和模型状态，以及项目文档。

| 能力 | 用法与局限 |
|---|---|
| EfficientSAM-S | 文字定位、元素组合、S 像素点选的统一后端。约 106 MB 权重，CPU 推理，最多 6 个正负提示点。支持曲线和孔洞；细枝、半透明物和复杂遮挡仍需修正。 |
| PyMatting | 基于已有选区的连续透明度细化，按需在 CPU 工作进程执行；不自动改写边缘 RGB，也不是换背景功能。 |
| OpenCV GrabCut | 对已有轮廓做边缘优化，默认手动触发；已有对象轮廓保留内部，仅重新判断较窄的边缘带。框选仍使用粗范围分割。相似背景或细发丝仍可能失败，优化失败保留原草稿，成功也可撤销。 |
| OpenCV 魔棒 | 点击连续的相近颜色；容差控制范围，支持添加和减去。 |
| U²-Net 小模型 | “选择主体”在 CPU 上自动分离显著主体/背景，不使用云端 Key；无法理解任意文字指令。模型输入 320px，不等于精细发丝抠图。 |

本机已配置 EfficientSAM-S/Ti 及约 4.6 MB 的 U²-Net 权重；应用默认 S，Ti 用于独立对照测试。新环境按 [本地模型说明](models/README.md) 显式安装。应用不会隐式下载模型、加载项目携带的代码，或把 Photoshop/Krita 插件当作可直接安装的本应用插件。

## 保存和撤销

**保存项目**保留原图引用、图层、嵌套组、矢量/位图蒙版、画面元素清单、选区/分区草稿及 AI 对话。首次保存默认建议原照片旁边的未占用项目名；后台保存失败会重新打开路径面板并保留错误和路径，方便改名或改位置重试。界面上的保存和自动恢复在后台串行写入；大项目保存时仍可继续调整参数，期间的新修改会保持未保存状态。**导出照片**在独立进程生成原尺寸合成 PNG / JPEG，默认建议原照片旁边的未占用文件名；内置示例建议存到用户目录。导出不会覆盖原图。弹窗会等到文件实际写成才关闭；大图导出可点“取消导出”，取消后保留弹窗以便重试。路径无效或导出中发生错误时也会留在弹窗内显示原因。**导出对话**会建议项目旁未占用的 Markdown 文件名；后台写入时可继续编辑，失败会带原路径与错误重新打开面板，改名后可直接重试，不会覆盖已有文件。阅读旧对话时，新消息不会强制滚走当前内容；顶部“新消息”按钮可跳到最新。输入修图要求后按 Enter 会提交并清空；请求未被接受时会保留原文供修改。

当前写入 1.7 项目格式，可读取旧版 0.1 / 1.2 / 1.3 / 1.4 / 1.5 / 1.6 项目；旧版应用不能读取新版项目。项目不嵌入原照片，请同时保留源图。原照片移动或原路径的文件被替换后，打开项目会提示选择原照片；后台核对文件摘要，匹配后才还原编辑，选错不会覆盖当前工作。找回后项目标为未保存，请按 Ctrl+S 更新照片位置。恢复副本也可通过此流程找回原照片。

未发送的修图文字及其“当前图层 / 只给建议 / 自动分区”模式按照片或项目分别保留；保存项目会写入当前草稿，退出前的自动恢复也会保护它。发送成功后清空当前草稿，未被接受的请求保留输入。草稿上限与单次修图要求一致，为 4000 字；写入文件时会隐藏 `sk-` 形式的 Key。

AI 请求期间，对话区和底部状态栏显示已等待时间、接收回复或网络重试倒计时；重试等待期间仍可点“取消”。这些提示表示客户端实际可观察的请求阶段，不展示模型内部推理内容。

修改后约 600ms 写入本地恢复副本，不同窗口独立保存。切换照片和退出前再次保存；失败时保留当前工作，允许另存或取消关闭。下次启动若有未保存会话，顶部会显示“恢复未保存”，也可从“文件”菜单恢复。恢复出的会话会显示未保存状态；保存为项目后，旧恢复副本才会清理。AI 设置中的 Key 不写入项目；用户输入里符合 `sk-` 形式的 Key 会被隐藏。

## 验证和能力边界

运行 `.\.venv\Scripts\python.exe -m pytest -q`。测试覆盖真实 Qt 鼠标/键盘流程、草稿事务、分区原子应用、每项调整的蒙版边界、透明通道、保存恢复、错误处理、本地分割与缓存一致性。自动测试默认使用本机模拟接口，不读取真实云端 Key。另外已按用户授权使用千问 Token Plan / qwen3.8-flash 对内置湖景做真实选区验收，失败、耗时与覆盖图分别记录在 [v1.4 验收记录](planning/iphoto-v1.4/delivery.md)。手动复测需显式运行 `scripts/qa_live_qianwen.py --live`，不能用 HTTP 成功代替轮廓质量检查。

选区外不变是每个图层相对于其输入合成图的保证。PNG 可逐像素验证；JPEG 有损重编码不能逐像素相等。普通位图选区由最长边 1600px 的代理图生成，保存时通常不超过 2048px；原图级透明边缘细化会保留原尺寸位图（最多 6000 万像素）。单纯放大普通选区不会创造新的边缘细节。

快速预览最长边 1600px；大图放大后仅可见区域按原分辨率渐进加载，不是一次性合成整张原图。64 MiB 像素缓存复用未变化的下层和组内合成结果；未变化的蒙版预览 PNG 也会复用，实际测量条件见交付记录。全尺寸导出耗时不能用预览耗时替代。

相机 RAW 通过 rawpy 解码为 8-bit sRGB 后编辑；HEIC/16-bit、曲线和色阶工具、裁切变形、生成式消除、SAM 2/3、专用发丝 matting、混合模式、PSD/8bf 和批处理尚未实现。修复画笔与内容感知填充使用 OpenCV，适合较小瑕疵；大孔洞可能留下模糊痕迹。柔化是普通滤镜，不是 AI 降噪。

# iPhoto 1.6.0

基于 Qt 6 / PySide6 的 Windows 原生修图工作室。采用独立选区、调整图层和 AI 助手的操作方式，无需 Electron 或 WebView。

双击 [start-iphoto.cmd](start-iphoto.cmd) 启动。新窗口标题应为 **iPhoto 1.6.0**，已打开的旧窗口不会自动更新。开发环境为 Python 3.12；其他电脑先运行 `scripts/setup.ps1`，再运行 `scripts/setup_segmentation.py` 安装选区模型。目前是源码与启动器，尚无独立安装包。

## 本次重点：透明边缘与调色预览

已有局部调色出现白边时：右侧选中图层 → 载入层蒙版 → “细化透明边缘”（默认 8px）→ 预览切换“调色效果”检查 → “替换当前层蒙版”。结果仍是可撤销的草稿，原图不变。也可以查看黑白透明度，确认边缘有连续灰度，而非只有全选 / 不选。

本地 PyMatting 根据前景、背景与未知边缘估计透明度；修复了内羽化把半透明覆盖度再次相乘的问题。该功能无需 Key。安装脚本会预初始化求解器，第一次编译可能需要数分钟；本机已完成。树枝、毛发等边缘仍需检查，颜色污染和复杂透明材质不能只靠 alpha 完全解决。

[行业调研、实现和后续验收计划](planning/iphoto-v1.6/alpha-matting.md)。新项目协议为 1.5，仍可读取旧项目。

## 像素自动选区

AI 只定位目标；本地 EfficientSAM 从照片生成位图蒙版，不再将 AI 多边形直接当成最终选区。按 **S** 在目标内部点击，**Alt＋点击**排除背景，不需要云端 Key。顶部可“退一点”或开始“新目标”；已有草稿在右侧点“补点修正”。框选目标后可点“重新贴边”。检查复杂边缘后，再输出到调整层。

文字选区、元素组合和 AI 分区均通过像素分割。首次需要编码图片，在本机约十几秒；同图后续目标复用特征。失败或取消会保留原选区，取消需等待当前推理结束。分割后可以另做透明边缘细化；最长边 1600px 的蒙版仍不等于原图级细节。

## 按你要做的事情开始

**整张照片调色**：打开 JPEG / 8-bit PNG，选择右侧“全图调整”，用滑杆或下方 AI 助手描述要求。手动调过的参数会锁定，AI 保留这些值，点击“解锁”可解除。

**先看清画面里有哪些对象**：打开右侧“元素”，点击“分析画面元素”。识别后可按类别勾选、组合新选区、添加、减去或相交；也可按 O 在画布悬停预览后点选。重叠处优先较小对象，清单可明确选择大背景。Shift 添加、Alt 减去。

**只改一个区域**：打开右侧“选区”，描述“选中天空，排除树枝和山峰”。首次分析元素，随后逐对象生成像素蒙版；后续描述复用清单，不重复上传照片。清单没包含目标时，用“直接识别此目标”补充，或按 S 像素点选、M 框选、L 套索、B 画笔手动选。W 是颜色魔棒，只选连续相近颜色。检查结果后点击 **选区 → 新建调整层**。之后的滑杆与“当前图层”AI 修图只影响这个图层的蒙版范围。

**让 AI 分开修多个区域**：在下方助手选择 **自动分区**，例如“人物提亮，背景压暗，分别调整”。AI 先给出最多四个区域和调整理由。逐区检查蒙版、勾选保留区域，需要时优化边缘，再点击 **确认并创建分区图层**。整组可一步撤销，每个图层之后也能单独微调。

第一次用云端服务，在右上角 **AI 设置**填写自己的 Key。千问 Token Plan、百炼、OpenAI 和兼容接口配置见 [AI 连接指南](docs/ai-connection.md)。只给建议模式会保存文字和候选参数，点击“应用建议”后才修改图层。

## 画布缩放与拖动

按住 **空格拖动**，松开回到原工具；**中键拖动**也可临时平移。按 **H** 使用抓手，双击画布或抓手按钮适应窗口。按 **Z** 使用缩放工具：单击放大，Alt＋单击缩小，左右拖动连续缩放；双击缩放按钮恢复 100% 比例。

**Alt＋滚轮**围绕鼠标位置缩放；普通滚轮上下移动，Shift＋滚轮左右移动。偏好直接滚轮缩放时，在“视图”菜单或画布右下角“?”切换（本次会话有效）。Ctrl＋加减按常用档位缩放，Ctrl+0 适应画布，Ctrl+1 回到原图 100% 尺寸比例；也可在底部直接输入百分比并回车。通常支持 1%–3200%，超宽长图的适应比例可低于 1%。

离开适应模式后，右下角导航图显示可见范围，可以点击或拖动定位。缩小图像也能拖动，边界会保留一部分图像，Ctrl+0 随时找回。调整窗口、展开 AI 助手时，适应模式自动重排；其他比例保留视图中心。透明 PNG 使用棋盘背景。

缩放按原图尺寸与屏幕 DPI 计算，但当前合成预览最长边仍为 **1600px**；底栏明确标注。100% 表示尺寸比例，大图在该比例下仍是预览放大，尚未实现原分辨率细节瓦片。缩放和平移不会修改照片、创建选区、增加撤销历史或触发重新合成。

## 选区与蒙版的区别

- 绘制和 AI 生成的是**独立选区草稿**，已有图层不变；“调色效果”模式可临时显示草稿结果。草稿有独立撤销/重做记录，Ctrl+D 取消草稿。
- “新建调整层”把选区变成一个新图层的蒙版。“替换当前层蒙版”明确修改当前层的作用范围。
- 点击图层蒙版缩略图，或“载入蒙版”，把原蒙版取出来继续修正。默认画笔为添加；X 切换添加/减去。
- 预览可选绿色覆盖、黑白透明度、调色效果或只看照片。羽化向内进行；位图可以保留孔洞、零碎区域和灰度过渡。
- 图层区的“＋ 调整层”建立全图调整层。每层一个蒙版；选中组时会在组内创建。
- “编组”或 Ctrl+G 将当前层放进新组，支持四级组嵌套，合计 32 个图层与组。可移入其他组、移出一级、展开折叠。组内先合成，再应用组蒙版与不透明度；隐藏组会隐藏所有后代。删除组会删除组内各层，可撤销。

## 本地图像能力

“图像能力”列出依赖和模型状态，以及项目文档。

| 能力 | 用法与局限 |
|---|---|
| EfficientSAM-S | 文字定位、元素组合、S 像素点选的统一后端。约 106 MB 权重，CPU 推理，最多 6 个正负提示点。支持曲线和孔洞；细枝、半透明物和复杂遮挡仍需修正。 |
| PyMatting | 基于已有选区的连续透明度细化，按需在 CPU 工作进程执行；不自动改写边缘 RGB，也不是换背景功能。 |
| OpenCV GrabCut | 对已有轮廓做边缘优化，默认手动触发；已有对象轮廓保留内部，仅重新判断较窄的边缘带。框选仍使用粗范围分割。相似背景或细发丝仍可能失败，优化失败保留原草稿，成功也可撤销。 |
| OpenCV 魔棒 | 点击连续的相近颜色；容差控制范围，支持添加和减去。 |
| U²-Net 小模型 | “选择主体”在 CPU 上自动分离显著主体/背景，不使用云端 Key；无法理解任意文字指令。模型输入 320px，不等于精细发丝抠图。 |

本机已配置 EfficientSAM-S/Ti 及约 4.6 MB 的 U²-Net 权重；应用默认 S，Ti 用于独立对照测试。新环境按 [本地模型说明](models/README.md) 显式安装。应用不会隐式下载模型、加载项目携带的代码，或把 Photoshop/Krita 插件当作可直接安装的本应用插件。

## 保存和撤销

**保存项目**保留原图引用、图层、嵌套组、矢量/位图蒙版、画面元素清单、选区/分区草稿及 AI 对话。**导出照片**生成原尺寸合成 PNG / JPEG。对话可复制和导出 Markdown。

v1.4 可以读取旧版 0.1 / 1.2 / 1.3 项目，写入时使用 1.4 格式；旧版应用不能读取新版项目。项目不嵌入原照片，请同时保留源图；源文件摘要不一致时拒绝套用旧编辑。当前尚无源图重新定位功能。

修改后约 600ms 写入本地恢复副本，不同窗口独立保存。切换照片和退出前再次保存；失败时保留当前工作，允许另存或取消关闭。恢复入口位于“文件”菜单。项目与对话不保存 Key。

## 验证和能力边界

运行 `.\.venv\Scripts\python.exe -m pytest -q`。测试覆盖真实 Qt 鼠标/键盘流程、草稿事务、分区原子应用、每项调整的蒙版边界、透明通道、保存恢复、错误处理、本地分割与缓存一致性。自动测试默认使用本机模拟接口，不读取真实云端 Key。另外已按用户授权使用千问 Token Plan / qwen3.8-flash 对内置湖景做真实选区验收，失败、耗时与覆盖图分别记录在 [v1.4 验收记录](planning/iphoto-v1.4/delivery.md)。手动复测需显式运行 `scripts/qa_live_qianwen.py --live`，不能用 HTTP 成功代替轮廓质量检查。

选区外不变是每个图层相对于其输入合成图的保证。PNG 可逐像素验证；JPEG 有损重编码不能逐像素相等。位图蒙版最长边上限 2048，当前本地选区算法在预览尺寸处理；放大到原图不会创造新的边缘细节。

预览最长边 1600px；新画布支持原图尺寸比例与 DPI 换算，但大图的 100% 不是原分辨率细节预览。64 MiB 像素缓存复用未变化的下层和组内合成结果；未变化的蒙版预览 PNG 也会复用，实际测量条件见交付记录。全尺寸导出耗时不能用预览耗时替代。

RAW/HEIC/16-bit、曲线和色阶工具、裁切变形、修复画笔、生成式消除、SAM 2/3、专用发丝 matting、混合模式、PSD/8bf 和批处理尚未实现。柔化是普通滤镜，不是 AI 降噪。

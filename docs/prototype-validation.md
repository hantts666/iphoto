# iPhoto 0.1 原型验证

日期：2026-09-22。状态：可运行的本地编辑原型，尚非完整 AI 修图产品或独立安装包。

当前环境实际使用 Python 3.12.14、PySide6 Essentials 6.10.2、NumPy 2.3.5、Pillow 12.3.0。原型在本机虚拟环境中运行；该虚拟环境借用了当前桌面工具提供的基础 Python，跨机器应重新创建虚拟环境。

**自动化验证**

执行 `.venv/Scripts/python.exe -m pytest -q`：22 passed。

覆盖：非法/非有限参数拒绝；零参数中性；透明通道保留；曝光在线性光域计算；分条参考计算一致；三个预设的 LUT 与浮点参考误差；EXIF 方向；ICC；拒绝覆盖原文件或既有导出；导出像素与尺寸；无效色彩配置；手动字段锁定；拒绝不能支持的文字请求；worker 错误恢复；真实 Qt 控制层的连续调参、撤销重做、项目保存恢复和导出。

LUT 回归使用固定随机 RGB 样本，门槛为平均通道误差 < 0.3/255、99.9% 通道误差 ≤ 2/255、最大误差 ≤ 5/255。它验证三个内置预设的数值逼近，不代表所有滑杆组合或照片审美质量已经通过完整评测。

执行 `scripts/verify_ui.py`：真实 QML 控件的文字输入提交、撤销按钮、对比切换、参数滑杆与画面更新通过；保存实际运行截图到 `artifacts/iphoto-preview.png`。截图通过 Qt 自身渲染生成，不是静态设计图。

**性能记录**

基准脚本将内置示例重采样为 6000×4000 JPEG，用于负载测试；不是真实相机样片的质量评估。

| 指标 | 本次结果 |
| --- | --- |
| 24MP 解码、方向/色彩处理与文件哈希 | 0.653 秒 |
| 1600px 预览第一次渲染（含 LUT 编译） | 1000 ms |
| 后续四次预览渲染 | 659 / 612 / 551 / 732 ms |
| 24MP JPEG 导出 | 9.157 秒 |
| 基准进程峰值工作集 | 512.0 MiB |

预览计时不含 PNG 编码、IPC、Qt 显示；峰值仅为基准进程，不是完整应用进程树。测试受当时电脑负载影响。样本数量不足以声称 P95；原方案的 500ms 预览目标尚未达成。原始结果由脚本写入 artifacts/benchmark.json。

最初的纯浮点逐像素导出约 29 秒。优化后，使用相同 LUT 进行预览/导出，并对饱和度色域边界采用浮点修正，在维持上述误差门槛后约为 9 秒。后续应重点减少色域修正开销、PNG 编码和界面更新延迟。
